# Mini Projects

Put everything together by building small console applications. Each project uses OOP, exception handling, collections, and file I/O from earlier topics.

## Folder Structure

Each sub-topic has:
- `src/` — Java source files (.java)
- `out/` — Compiled class files (.class)
- `notes.md` — Concept notes

## Sub-Topics

1. **01-library-management** — Add, remove, search, issue, and return books by member
2. **02-atm-simulator** — Login with PIN, deposit, withdraw, balance check, mini-statement
3. **03-student-grade-system** — Add students, record marks, compute grades, sort by rank
4. **04-quiz-app** — Load questions from a file, ask user, score, and save results
